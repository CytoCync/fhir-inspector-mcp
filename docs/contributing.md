# Contributing

We welcome contributions to the FHIR Inspector MCP project!

## How to Contribute

1. **Fork the Repository**: Fork the project on GitHub.
2. **Create a Branch**: Create a new branch for your feature or bug fix.
3. **Make Changes**: Implement your changes.
4. **Run Tests**: Ensure all tests pass by running `pytest`.
5. **Submit a Pull Request**: Open a pull request with a clear description of your changes.

## Development Guidelines

- **Code Style**: Follow PEP 8 guidelines.
- **Testing**: Add tests for any new features or bug fixes.
- **Documentation**: Update documentation if you change any functionality.

## Reporting Issues

If you find a bug or have a feature request, please open an issue on our [GitHub repository](https://github.com/CytoCync/fhir-inspector-mcp/issues).

This section outlines how to contribute to the FHIR Inspector MCP project.
